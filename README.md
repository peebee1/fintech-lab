# fintech-lab

Daily artifacts on AI native fintech infrastructure. Each one is built, tested, and
measured in a single run: a payments primitive, the edge cases that break it, and the
number that shows whether it holds.

No screenshots of claims. Every entry below has code, a test suite, and a reproducible result.

I build agentic commerce and payments systems for a living. This repo is the part of that
work that can be made public: the primitives, the failure modes, and the measurements.

## How this repo works

| Piece | What it does |
|---|---|
| `RUBRIC.md` | The scoring rules: hard gates, seven weighted dimensions, anti repetition, promotion bar |
| `tools/select.py` | Picks the next item deterministically, including penalties for repeating a theme |
| `tools/gate.py` | Binary quality gate: tests pass twice, README sections present, no secrets, measured output exists, size cap |
| `tools/render_readme.py` | Regenerates this dashboard, `BACKLOG.md`, and `HARDENING.md` from `state/*.json` |
| `state/backlog.json` | Every idea that survived scoring, with its scores |
| `state/hardening.json` | Defects in my other public repos, ranked by impact x confidence / effort |
| `artifacts/` | One directory per build, each self contained |
| `social/queue/` | Draft posts pulled from the day's result. Nothing is auto posted |

The rule that keeps this honest: **a build that fails the gate is parked, not pushed.**
The ledger records failures too.

## Layout of an artifact

```
artifacts/YYYY-MM-DD-slug/
  README.md      problem, why it matters, design, run, results, limits, next
  tests/         deterministic, no network, no clock
  results/       measured output, generated by committed code
```

## Run it

```bash
uv sync
uv run pytest                      # every artifact
uv run python tools/select.py       # what should I build next
uv run python tools/gate.py artifacts/<name>
```

## What this is not

Not a tutorial collection, not a star farm, and not a place to park half finished ideas.
Anything that fails `tools/gate.py` does not get pushed, and anything that ships without a
number gets retired at the weekly recap.
