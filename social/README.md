# Social queue

One draft per ship, written for LinkedIn. Nothing here is posted automatically: you read
it, edit the first line if it does not sound like you, and post it.

Rules for these drafts:

- First line is the hook and it has to survive being read alone.
- No em dashes, no "excited to share", no "delve", no fake humility.
- One number from the artifact, quoted exactly as the eval produced it.
- One limit stated out loud. Posts that admit a limit get more trust than posts that do not.
- Link to the code, never to a screenshot of the code.
